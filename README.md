# Dead Pixel Test

A single-file, offline display tester. Fill your screen with solid colors and look for dots that stay a different color.

## Usage

1. Open `dead-pixel-test.html` in any modern browser (or the GitHub Pages link, if enabled).
2. Pick a color, run the full test, or start the auto-cycle.
3. Look closely at the whole screen.

## Controls (test mode)

| Key / action | Result |
|---|---|
| Click, tap, Space, Right arrow | Next color |
| Left arrow | Previous color |
| Esc | Exit |

Press F11 first for true full screen on desktop.

## What to look for

- **Dark dot on white:** dead pixel
- **Bright dot on black:** stuck pixel
- **Dot visible only on red, green or blue:** faulty subpixel

## Features

- 16 preset colors, including black, white, RGB primaries, secondary colors and grays
- Custom color picker
- Full test sequence and 2-second auto-cycle
- No dependencies, no network access, one HTML file
