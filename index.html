Dead pixel test

Fill the whole screen with one color and look for dots that stay a different color. Dark dots on white are dead, bright dots on black are stuck.

Run all

Controls in test mode

  • Click, tap, or Right arrow / Space: next color
  • Left arrow: previous color
  • Esc: exit

Tips

  • Press F11 first for true full screen on desktop; the test also requests it.
  • Clean the screen so dust isn't mistaken for a pixel fault.
  • Check red, green and blue separately to find single-subpixel faults.
  • Run it from a few centimeters away, then at normal distance.
